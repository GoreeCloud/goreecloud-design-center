# GoreeCloud Design Center — Features

This file records features implemented in the current Development source. Planned work belongs in `FEATURE-ROADMAP.md`.

## Implemented

- Mobile-first responsive application shell.
- Compact, Medium, Expanded, and Wide composition behavior.
- Light, Dark, Deep Dark, and system appearance selection.
- Repository-local product mark and favicon.
- Local catalog search with keyboard shortcut support.
- Material-hierarchy and protected-semantic reference surfaces.
- Runtime semantic-token inspector that reads computed Glaze values without redefining token authority.
- Component specimens for actions, fields, choices, Universal Search, unavailable, degraded, and validation-failure states.
- Accessibility reference surfaces covering Reduced Motion, Reduced Transparency, Forced Colors, 200% text/reflow, keyboard focus, and touch target guidance.
- Exact-revision Glaze UI build synchronization with local vendoring.
- Automated source/build validation and GitHub Actions artifact generation.
- GoreeCloud Platform Contract `0.3` declaration with all eight Integral Platform Systems represented.

## Not represented as complete

The current source is not production deployed, Stable, fully platform-conformant, or application-acceptance complete.
