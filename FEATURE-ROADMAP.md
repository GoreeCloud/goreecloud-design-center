# GoreeCloud Design Center — Feature Roadmap

**Lifecycle:** Development

Roadmap items are proposed work, not implementation claims.

## Near term

- Migrate the implemented Glaze source from `1.4.0` to the current required Stable `1.4.1` through an exact pinned source update, source/build validation, and application-specific acceptance; do not rewrite the implemented version before that work exists.
- Expand semantic token inspection with comparison and provenance views.
- Add broader current-Stable Glaze component/state specimens after the applicable 1.4.1 source migration is in place.
- Add design-state export and shareable deep-link workflows where they can remain local-first.
- Add automated rendered regression evidence for representative Mobile, Tablet, Desktop, and Wide Desktop compositions.
- Complete repository-local identity derivatives required by supported surfaces.
- Define and approve the application umbrella identity through the governed GoreeCloud naming and identity process; do not invent an interim canonical identity.

## Documentation and authority

- Keep repository implementation documentation reconciled with the canonical `GoreeCloud/Projects/Project Specification — Design Center` record.
- Preserve exact source truth separately from current platform requirements when Glaze UI, Platform Contract, or another shared authority advances.

## Platform and acceptance work

- Complete applicable GoreeCloud Manager, Privacy Shield, Wardveil Security, Everkeep, Glaze UI, GoreeCloud Mesh, GoreeCloud Identity, and GoreeCloud Sync evaluations and accepted integrations.
- Add supported API access before any future production-readiness claim when the approved production architecture requires it.
- Complete accessibility, browser/platform, performance, deployment, rollback, and production acceptance.
- Keep Glaze UI migration continuous whenever a later Stable Glaze release supersedes the implemented source version.

No roadmap item changes lifecycle until implementation and required evidence are verified.
